# Loop Engineering for Beginners

From the How I AI podcast. Video. [Watch the original](https://www.youtube.com/watch?v=JoXbk2fm7jM).

This is a pointer, not a copy. The full piece belongs to its author, so my public repo links to it. I keep my own copy in my private workspace, where my skills and notes reference it.

A beginner's guide to loops: an agent that runs on a trigger instead of a typed prompt. It covers four loop types (heartbeat, cron, hook, and goal) and frames a loop as designing a job for an employee.
