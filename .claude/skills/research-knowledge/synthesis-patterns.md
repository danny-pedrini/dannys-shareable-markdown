# Synthesis Patterns

Choose the pattern that matches the user's research goal. Each pattern provides a synthesis structure optimized for that type of research.

## Pattern 1: Feature Discovery

**Goal:** Understand what features exist in the market for a capability.

```markdown
# [Capability] Feature Landscape

## Feature Categories
| Category | Common Features | Best-in-Class Examples |
|----------|-----------------|------------------------|

## Feature Comparison Matrix
| Feature | Vendor A | Vendor B | Vendor C | Our Current State |
|---------|----------|----------|----------|-------------------|

## Recommended Feature Priorities
1. **Must Have:** [Features with strong consensus across sources]
2. **Should Have:** [Features mentioned by multiple leaders]
3. **Could Have:** [Emerging/innovative features]
4. **Won't Have (for now):** [Overly complex or low ROI]
```

## Pattern 2: Best Practices

**Goal:** Learn how leading organizations approach a problem.

```markdown
# [Topic] Best Practices Reference

## Maturity Model
| Level | Characteristics | Examples |
|-------|-----------------|----------|
| Basic | ... | ... |
| Developing | ... | ... |
| Advanced | ... | ... |
| World-Class | ... | ... |

## Best Practices by Category

### [Category 1]
**The Practice:** [What to do]
**Why It Works:** [Evidence from sources]
**How to Implement:** [Practical steps]
**Watch Out For:** [Common pitfalls]

## Implementation Roadmap
1. **Quick Wins (0-30 days):** ...
2. **Foundation Building (1-3 months):** ...
3. **Advanced Optimization (3-6 months):** ...
```

## Pattern 3: Vendor/Technology Evaluation

**Goal:** Compare solutions for a capability.

```markdown
# [Technology] Evaluation Summary

## Market Landscape
[Overview of the space and key players]

## Evaluation Criteria
| Criterion | Weight | Why It Matters |
|-----------|--------|----------------|

## Vendor Comparison
| Vendor | Strengths | Weaknesses | Best For |
|--------|-----------|------------|----------|

## Recommendation
**For our context:** [Specific recommendation with rationale]
**Key risks:** [What could go wrong]
**Next steps:** [How to proceed with evaluation]
```

## Pattern 4: Problem-Solution

**Goal:** Understand challenges and how others solved them.

```markdown
# [Problem Domain] - Challenges & Solutions

## Problem Landscape
| Challenge | Impact | Frequency |
|-----------|--------|-----------|

## Solution Approaches

### Approach 1: [Name]
**What it is:** [Description]
**Who uses it:** [Examples]
**Results:** [Outcomes from sources]
**Applicability to us:** [Assessment]

## Decision Framework
IF [condition] THEN consider [approach]

## Recommended Solution for Our Context
[Specific recommendation with evidence]
```
